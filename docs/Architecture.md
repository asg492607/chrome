# PacketForge Architecture

PacketForge is a modular Internet Computing Platform that simulates a full network, search, and browser environment locally.

## Subsystems
1. **Core Platform**: Utilities, logging, config, models.
2. **Networking Stack**: DHCP, DNS, Reverse Proxy, Mock Server.
3. **Browser Engine**: Parsing, Styling, Layout, Rendering pipelines.
4. **Search Platform**: Crawler, Index Builder, TF-IDF engine, Search API.
5. **Dashboard**: Granular metrics and telemetry panels.
6. **Platform Orchestration**: Event Bus, Dependency Container, Lifecycle management.
