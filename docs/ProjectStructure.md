# Project Structure

- `application/`: Orchestration and event bus.
- `browser_engine/`: UI and rendering.
- `core_platform/`: Shared config and logs.
- `dashboard/`: Telemetry panels.
- `networking_stack/`: DHCP, DNS, Proxy.
- `search_platform/`: TF-IDF search index.
- `tests/`: QA suite.
- `docs/`: Documentation.
