Demystifying DHCP and DNS Protocols

← Back to Blog Home

To understand the internet, we must understand how nodes join networks. This happens in two steps:

1. DHCP: The Handshake (DORA)

Before a client can send IP packets, it needs a leased IP. It sends a UDP broadcast searching for a server:

Client -> DISCOVER (Broadcast)
Server -> OFFER (Proposed IP)
Client -> REQUEST (Claim IP)
Server -> ACK (Confirm Lease)

This four-way handshake is called DORA.

2. DNS: The Translator

Computers communicate via IP addresses (like 127.0.0.1), but humans prefer domains (like asgsearch.local). The DNS translates domains to IPs over UDP port 53. The client queries the domain, and the server returns the IP record.

Once DNS returns the IP, the browser opens a TCP socket connection (on port 80/443 or a proxy port like 8080) to fetch the website payload.
